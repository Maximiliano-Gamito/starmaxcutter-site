Política de Privacidade

1. Escopo

Esta política descreve como o StarMaxCutter trata informações utilizadas para autenticação e integração com o TikTok.

2. Informações utilizadas

  • Dados básicos da conta TikTok fornecidos pela API, quando autorizados pelo usuário;
  • Tokens necessários para manter a autorização e realizar chamadas permitidas;
  • Dados de agenda e arquivos de vídeo informados pelo usuário para execução das funções do aplicativo.

3. Finalidade

As informações são utilizadas para autenticar o usuário, manter a autorização, organizar agendamentos e executar operações de publicação ou envio de conteúdo solicitadas pelo titular da conta.

4. Compartilhamento

O aplicativo não deve vender dados pessoais. As informações são enviadas ao TikTok somente quando isso é necessário para executar uma operação autorizada pelo usuário.

5. Segurança

Credenciais, tokens e arquivos locais devem ser armazenados com controles de acesso adequados. O operador desta aplicação deve substituir esta página por uma política compatível com sua infraestrutura real antes da publicação.

6. Retenção e exclusão

Os dados devem ser mantidos apenas pelo período necessário às finalidades descritas e removidos conforme as solicitações do titular e as obrigações legais aplicáveis.

7. Contato

Substitua esta seção pelos dados reais de contato do operador do aplicativo antes da publicação.

8. Atualizações

Esta política poderá ser atualizada quando as funcionalidades ou práticas de tratamento forem alteradas.
